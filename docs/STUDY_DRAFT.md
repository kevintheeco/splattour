# 사용자 실험 설계 초안 (RQ1)

> **초안**이다. 연구 질문과 가설, 설계의 최종 결정은 주희가 한다. 아래는 지금 시스템으로 바로 돌릴 수 있는 형태로 정리한 제안이다.

## 1. 질문
**RQ1.** 3DGS 공간을 **연속 비행으로 이동**하는 가상 투어(3D 조건)는 기존 **파노라마 크로스페이드** 투어(파노라마 조건)보다 공간 이해·실재감·사용성이 높은가? 멀미는 늘어나는가?

## 2. 조건 (참가자 내 설계, within-subjects)
| 조건 | 주소 설정 | 통제 |
|---|---|---|
| 3D 연속 비행 | `mode=splat` | 같은 3DGS 모델·같은 시점 그래프·같은 화각 범위 |
| 파노라마 크로스페이드 | `mode=pano` | 파노라마는 같은 모델을 각 시점에서 렌더링(화질 동일) |

- 공간 두 개(예: 한옥 A, 호텔 객실 B)를 준비해 **조건 × 공간을 교차**한다. 한 사람이 같은 공간을 두 번 보지 않게 한다.
- 순서는 **라틴 방격으로 상쇄**한다(순서 효과 제거). 예: P01 = 3D·A → 파노·B, P02 = 파노·A → 3D·B, P03 = 3D·B → 파노·A, P04 = 파노·B → 3D·A, 이후 반복.
- 공통 설정: `onboarding=0`(실험자가 같은 설명을 구두로), `vignette` 고정, `badge=0`(참가자에게 기록 표시 숨김).

## 3. 과제 (예시)
1. **자유 탐색** 3분: "이 공간을 처음 방문했다고 생각하고 둘러보세요."
2. **찾기 과제** 3개: "침대 머리맡의 액자를 찾아 가까이 보세요." 과제마다 `task=T1…T3`로 기록해 소요 시간을 잰다.
3. **공간 이해**: 탐색 후 평면도에 방 배치·가구 위치를 그리게 하고 실제와 비교해 채점한다(인지 지도).

## 4. 측정
| 측정 | 도구 | 비고 |
|---|---|---|
| 과제 소요 시간·이동 횟수·이동 거리·확대·다가가기 | 자동 기록 (`?study=`, `study_report.py`) | 객관 행동 |
| 실재감 | IPQ (Igroup Presence Questionnaire) | 조건마다 |
| 사용성 | SUS (System Usability Scale) | 조건마다 |
| 멀미 | SSQ (Simulator Sickness Questionnaire) | 실험 전·각 조건 후 |
| 공간 이해 | 평면도 스케치 채점 | 조건마다 |
| 선호·이유 | 반구조화 인터뷰 | 마지막 |

## 5. 분석 (제안)
- 짝지은 비교: 정규성 따라 대응 t 검정 또는 Wilcoxon 부호순위 검정. 효과 크기(Cohen's d 또는 r) 보고.
- 순서·공간을 무작위 효과로 둔 혼합 모형(선택).
- 이동 경로를 평면도 위에 겹쳐 그린 히트맵(0.25초 위치 기록으로 바로 그릴 수 있음).

## 6. 참가자 수
대응 설계에서 중간 효과(d≈0.5)를 α=.05, 검정력 .8로 잡으려면 약 **34명**. 파일럿 5~6명으로 과제 난이도와 소요 시간을 먼저 맞춘다.

# 다른 컴퓨터에서 업로드하기 (아직 열지 않음, 결정 대기)

지금 SplatTour Studio는 이 노트북 안(`http://localhost:5200`)에서만 열린다. 주희가 자기 컴퓨터에서 촬영본을 올리려면 인터넷 주소가 필요하다.

## 방법 A. 임시 공개 주소 (Cloudflare Tunnel, 계정 불필요)
1. 비밀번호 정하기: `secrets/studio_password.txt`에 한 줄로 저장. 있으면 브라우저가 처음 한 번 물어본다(아이디는 아무거나).
2. Studio 켜기: `pipeline/.venv/Scripts/python.exe studio/server.py`
3. 터널 켜기: `cloudflared tunnel --url http://localhost:5200` → `https://xxxx.trycloudflare.com` 주소가 나온다. 이 주소와 비밀번호를 주희에게 전달.
4. 끝나면 터널 창을 닫는다(주소가 바로 사라진다).

- 장점: 5분이면 된다. 끊겨도 같은 폴더를 다시 올리면 이어서 올라간다.
- 단점: 노트북이 켜져 있어야 한다. 업로드 속도가 노트북의 인터넷 속도에 묶인다. 주소가 매번 바뀐다.

## 방법 B. 클라우드 저장소로 바로 올리기 (나중)
주희가 올린 파일을 노트북을 거치지 않고 클라우드 저장소(예: RunPod 네트워크 볼륨의 S3 API, R2)에 두고, GPU 서버가 거기서 바로 읽는다. 수십 GB를 반복 학습할 때 가장 빠르다. 계정과 요금 설정이 필요하다.

> 어느 쪽이든 **외부에 공개하는 일**이라 대표 승인 후 진행한다.

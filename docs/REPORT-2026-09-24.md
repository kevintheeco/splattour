### 클라우드 학습을 쓸 만하게 만든 수정 (총 6번 시도 끝에)
- 업로드: 먼 GPU 서버(미국)로 한 줄 전송이 0.1MB/s → **8줄 동시 전송 6~10MB/s** (147MB를 15~23초)
- 설치: 매번 8~14분 → 한 번 빌드한 부품을 노트북에 저장해 재사용, **25초**
- 잘못 등록된 카메라 13대가 학습을 망가뜨림 → 학습 전에 자동으로 제거
- 사진별 밝기 보정(bilateral grid)이 색을 틀어지게 함 → 기본값에서 끔(보정 켠 결과는 소거 실험 자료로 보관)
- 점 400만 개 ↔ 200만 개 화질이 같음 → 기본 200만 개(파일 절반)
- GPU 서버마다 네트워크 속도 편차가 큼(0.2~10MB/s) → 업로드 전에 속도를 재서 느린 서버는 반납하고 다시 빌림
- **업로드 화면의 실제 흐름 그대로 끝까지 검증**: 사진 80장 → 정리 → 카메라 복원 → 클라우드 학습 → 투어 → 웹 압축(휴대폰용 포함) 자동 완주
- **안전장치**: 모든 학습 비용을 장부(`secrets/cloud_ledger.jsonl`)에 기록하고 한 달 한도(기본 $30)를 넘으면 GPU를 빌리지 않음. 노트북이 꺼져 남은 GPU는 다음 학습 때 자동 정리. 업로드 화면에 이번 달 사용액 표시.
- GPU는 끝나거나 실패하면 즉시 반납. **오늘 총 GPU 비용 약 $1.9** (장부 기준 $1.68 + 실패 추정) (예산 $10)

# SplatTour 촬영 가이드

3D 가우시안 스플래팅(3DGS) 투어의 화질은 **촬영이 절반 이상**을 결정합니다. 사진에 찍히지 않은 것은 복원되지 않고, 흔들리거나 노출이 들쭉날쭉한 사진은 그대로 번짐과 얼룩이 됩니다. 이 문서대로 찍으면 "확대해도 사물이 사실적으로 보이는" 결과를 얻을 수 있습니다.

---

## 1. 한 줄 요약

> **같은 노출·같은 초점으로, 흔들림 없이, 한 곳을 여러 방향에서 겹치게.**
> 방 하나에 사진 150~400장, 또는 4K 영상 3~6분.

---

## 2. 장비

| 우선순위 | 장비 | 이유 |
|---|---|---|
| 가장 좋음 | 미러리스/DSLR + 광각 단렌즈(환산 20~28mm) | 큰 센서라 실내에서도 노이즈가 적고 선명. 단렌즈라 화각이 고정됨 |
| 좋음 | 최신 폰의 **기본 1x 카메라** | 충분히 좋음. 0.5x 초광각은 가장자리가 흐려서 비추천 |
| 보조 | 360 카메라(인스타360 X4 등) | 빠르게 전체를 담을 때. 해상도가 나뉘어 디테일은 약함 → 일반 카메라와 **같이** 찍으면 가장 좋음 |
| 있으면 좋음 | 작은 삼각대 또는 모노포드 | 어두운 방에서 흔들림 방지 |

폰으로 찍는다면 **영상보다 사진**이 선명합니다. 영상은 빠르지만 프레임마다 압축·흔들림이 섞입니다.

---

## 3. 카메라 설정 (가장 중요)

찍기 전에 **한 번 맞추고, 촬영 내내 바꾸지 않습니다.**

1. **노출 고정 (AE Lock / 수동 M 모드)**
   사진마다 밝기가 바뀌면 3D에서 벽에 얼룩덜룩한 무늬가 생깁니다.
    - 카메라: M 모드, ISO 400~1600, 셔터 1/125초 이상(손으로 들 때), 조리개 f/5.6~f/8
    - 폰: 화면을 길게 눌러 **AE/AF 잠금**. 전문가 모드가 있으면 ISO·셔터를 고정
2. **초점 고정**: 1.5~2m에 맞추고 잠급니다(f/8이면 대부분 선명).
3. **화이트밸런스 고정**: 자동(AWB)이면 방향마다 색이 달라집니다. "태양광"이나 켈빈 값으로 고정.
4. **HDR·인물 모드·뷰티·AI 보정 끄기**: 사진마다 다르게 가공돼 3D가 헷갈립니다.
5. **해상도**: 가장 높게(1,200만~2,400만 화소). 파일은 JPG 최고 화질이면 충분합니다(RAW도 가능).
6. **영상으로 찍을 때**: 4K, 30fps 이상, 셔터 1/120초 이상(모션블러 감소), 손떨림 보정 **켜기**.

## 4. 어떻게 걸으며 찍나

### 4-1. 방 하나 찍는 순서

```
      ┌────────────────────┐
      │  ②벽 따라 한 바퀴  │
      │   ┌──────────┐     │
      │   │ ①가운데서 │     │
      │   │  한 바퀴  │     │
      │   └──────────┘     │
      │  ③중요한 사물은     │
      │   가까이서 한 번 더  │
      └────────────────────┘
```

1. **가운데서 한 바퀴**: 방 가운데에 서서, 몸을 돌리며 **한 장 찍고 한 걸음(약 20~30°) 돌기**. 한 바퀴에 12~18장.
2. **벽 따라 한 바퀴**: 벽에서 1~1.5m 떨어져 방을 따라 걸으며, **방 가운데 쪽을 향해** 찍습니다. 1~2걸음마다 한 장.
3. **높이 두 번**: 1, 2를 **눈높이(약 1.5m)**와 **가슴 아래(약 1m)**에서 한 번씩. 가구 위·아래가 모두 복원됩니다.
4. **중요한 사물은 가까이**: 액자·책장·침대·조명처럼 확대해서 볼 만한 것은 50~80cm 앞에서 조금씩 옆으로 옮겨 가며 5~10장. 이게 **"확대해도 선명한"** 부분을 만듭니다.

### 4-2. 겹치기 규칙

- 옆 사진과 **70% 이상 겹치게**(한 장에서 보였던 것이 다음 장에도 대부분 보이게).
- **제자리에서 카메라만 돌리지 말고 조금씩 걸어가며** 찍기. 같은 자리에서 돌리기만 하면 깊이를 못 잡습니다(①의 가운데 한 바퀴는 예외, ②와 같이 찍기 때문에 괜찮음).
- 너무 가까이(30cm 이내) 붙어서 벽만 찍힌 사진은 위치를 못 잡습니다. 한 장에 **벽 모서리나 가구가 같이** 보이게.

### 4-3. 방과 방 연결 (투어 동선의 핵심)

- 문지방은 **앞으로 한 번, 뒤로 한 번** 지나가며 찍기(문 앞 · 문턱 · 문 안쪽 각 2~3장).
- 복도는 걸어가면서 1~2걸음마다 한 장, 앞뒤 양방향.
- 방을 건너뛰지 말고 **걸어간 순서대로** 찍으면 연결이 끊기지 않습니다.

## 5. 피해야 할 것

| 문제 | 결과 | 해결 |
|---|---|---|
| 사람·반려동물·커튼이 움직임 | 유령 같은 얼룩 | 촬영 중엔 공간을 비우기. 선풍기·에어컨 바람도 끄기 |
| 창밖이 하얗게 날아감 | 창 주변이 번짐 | 낮에 커튼을 반쯤 치거나, 흐린 날 촬영 |
| 거울·유리·반짝이는 면 | 거울 속 가짜 방이 생김 | 거울은 천으로 덮거나, 거울 정면은 피해서 찍기 |
| 아무 무늬 없는 흰 벽만 | 위치를 못 찾음 | 가구·모서리·문틀을 같이 담기 |
| 조명이 촬영 중 켜졌다 꺼졌다 | 밝기 얼룩 | 조명은 처음 상태 그대로 유지 |
| 흔들린 사진 | 번진 부분 | 멈추고 찍기. 자동으로 흐린 사진은 걸러지지만 너무 많으면 빈 곳이 생김 |

## 6. 한옥처럼 밝기 차이가 큰 곳

- 마당(아주 밝음) ↔ 대청·방(어두움)은 **구역을 나눠** 찍어도 됩니다. 각 구역 안에서는 노출 고정.
  구역 경계(문턱·툇마루)는 **양쪽 노출로 두 번** 찍어 두면 이어 붙이기 좋습니다.
- 서까래·창살 같은 **가는 구조**는 가까이서 올려다보며 한 번 더.
- 처마 밖 하늘은 비워 둬도 됩니다(하늘은 자동 처리).

---

## 7. 조명 켜기/끄기 기능을 쓰려면 (논문 L3 실험)

같은 공간을 **두 번** 찍습니다. 같은 동선, 같은 카메라 위치를 최대한 비슷하게.

1. **낮**: 자연광, 조명 끔
2. **밤**: 커튼 치고 실내 조명만

두 촬영을 함께 복원하면 "낮 ↔ 밤" 슬라이더와 실제 조명 전환이 가능해집니다.

---

## 8. 360 카메라로 찍을 때

- 셀카봉을 머리 위 약 1.7m로 들고, 1걸음마다 한 장(또는 영상 천천히 걷기).
- 촬영자가 찍히지 않게 셀카봉 바로 아래에 서기.
- 방마다 가운데 1장 + 벽 따라 4~8장. 일반 카메라 사진과 **같이 올리면** 디테일이 크게 좋아집니다.

---

## 9. 파일 정리와 올리기

```
촬영_2026-10-01_북촌한옥/
  01_사랑채/        ← 방(구역)마다 폴더
  02_대청/
  03_마당/
  메모.txt          ← 날짜·날씨·카메라 설정·특이사항
```

- 파일 이름·날짜는 **바꾸지 말기**(촬영 순서를 알아내는 데 씀).
- **SplatTour Studio**(업로드 화면)에 **폴더째 끌어다 놓기** → "논문 품질 · 클라우드 GPU" 선택 → 올리고 투어 만들기.
    - 수십 GB도 조각으로 나눠 올라가고, 끊겨도 같은 폴더를 다시 끌어 놓으면 이어서 올라갑니다.
- 결과: 약 1시간 뒤 "완성된 공간"에 투어가 나타납니다.

## 10. 촬영 전 체크리스트

- [ ] 노출·초점·화이트밸런스 **잠금**
- [ ] HDR·AI 보정 **끔**
- [ ] 해상도 **최대**
- [ ] 공간에서 사람·움직이는 것 **치움**, 선풍기 **끔**
- [ ] 거울 **가림**
- [ ] 방마다: 가운데 한 바퀴 → 벽 따라 한 바퀴 → 낮은 높이 한 번 더 → 중요한 사물 가까이
- [ ] 문지방 **앞뒤로 두 번**
- [ ] (조명 기능) 낮·밤 **두 번** 촬영
- [ ] 폴더를 방별로 정리, 메모 남기기
